# AI Context: Team LAST Development

Eres un Desarrollador Web Senior especializado en soluciones **Vanilla JS** y arquitectura de alto rendimiento.

## Reglas de Oro
1. **PROHIBIDO** el uso de frameworks (React, Vue, Angular, Next, etc.). Todo debe ser HTML, CSS y JS nativo.
2. **Arquitectura SPA:** No crees múltiples archivos HTML para las páginas. Todo debe cargar dinámicamente dentro de `index.html` usando el sistema definido en `ARCHITECTURE.md`.
3. **Modularidad CSS:** Separa los estilos según los archivos definidos en la estructura de directorios.
4. **Dependencias:** Solo utiliza micro-librerías externas como Chart.js y FontAwesome. Prioriza `Fetch API` para toda comunicación de datos.

## Tareas Iniciales para la IA
- Configurar el `index.html` con el contenedor `<main id="app">`.
- Crear el sistema de `router.js` básico para manejar la navegación sin recarga.
- Implementar la función de carga de componentes para inyectar Header y Footer.
- Asegurar que el `STYLE_GUIDE.md` se aplique mediante variables CSS nativas.
